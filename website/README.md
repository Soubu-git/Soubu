# ［任意団体］総武鉄道 公式ウェブサイト

Robloxを中心に活動する任意団体・総武鉄道の静的ウェブサイトです。総武鉄道は実在の鉄道会社ではなく、Roblox上で活動する架空の鉄道コミュニティです。

## 使用技術

- HTML
- CSS
- JavaScript
- Zen Kaku Gothic New（外部フォントが使えない場合は日本語フォールバックを使用）

## フォルダ構成

- `index.html` トップページ
- `news.html` お知らせ
- `routes.html` 路線・駅情報
- `about.html` 団体について
- `regulations.html` 社員規定
- `recruitment.html` リンク・社員募集
- `contact.html` お問い合わせ
- `404.html` エラーページ
- `css/style.css` 共通スタイル
- `js/main.js` 共通データ・UI
- `assets/` ロゴ・画像用フォルダ

## 編集方法

サイト名、キャッチコピー、外部サービス名、ナビゲーションは `js/main.js` の `SITE` と `NAV_ITEMS` を編集します。

### 路線を追加する

`js/main.js` の `LINE_DATA` に、路線名と英字表記を追加します。現在は正式確定している快速線と各停線のみを掲載しています。

### ニュースを追加する

トップページとお知らせページの表示内容は、正式なお知らせが決まり次第、HTMLまたはJavaScriptのデータとして追加してください。未確認の日付や内容は作成しないでください。

### 駅を追加する

駅名・駅番号などが正式決定した後、路線ページに追加してください。現在は「準備中」表示です。

### 外部リンクを設定する

URLが確定した後、`js/main.js` の外部サービス表示部分にリンクを追加してください。未確定のURLは作成しないでください。

## GitHub Pagesへの公開

この `website` フォルダの内容をGitHubリポジトリの公開対象に置き、GitHub Pagesの公開元を設定します。サーバーサイド機能は使用していません。

## 注意事項

- 法人を示す表記は使用しません。
- 未設定の駅名、人物名、会社名、住所、連絡先、SNSアカウント、URL、数字を追加しないでください。
- 本サイトの鉄道・路線等はRoblox上で展開される架空のコンテンツです。
- お問い合わせフォームは入力確認のみで、送信機能は準備中です。
